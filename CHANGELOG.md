# Changelog

Формат: major.minor.patch. Даты в ISO 8601.

## 1.5.1 - 2026-10-23

### Исправлено

- Поля ввода больше не уезжают под клавиатуру: отступ снизу учитывает высоту клавиатуры, поле прокручивается в видимую область.
- Release подписывается signingConfig release из переменных окружения, CI проверяет отпечаток сертификата.

## 1.5.0 - 2026-10-23

### Добавлено

- Поддержка BLE-гарнитур Edifier: сервис 1100, запись 1101, уведомления 1102 и 1103, батарея 180F/2A19, чтение Device Information, Fast Pair в дампе GATT.
- Универсальный GATT-профиль для устройств без Nordic UART: автоматический выбор пары характеристик записи и уведомлений в одном сервисе.
- AI-ассистент: OpenAI Chat Completions, OpenAI Responses и Anthropic Messages, автоопределение формата по base URL, настройки URL, ключа и модели.
- Вызов инструментов из AI: сканирование, подключение, состояние, GATT, чтение и запись характеристик, уведомления, команды самоката, спам, перебор, настройки, журнал, обновления, навигация и данные Edifier.
- Отдельный экран AI-чата с историей, остановкой и очисткой.
- Примерное расстояние до устройства по RSSI, сортировка списка по расстоянию, имени, адресу или типу.
- Скрытие устройств с именем Unknown.
- Кнопка AI в шапке главного экрана.

### Изменено

- Удалён демо-режим без самоката.
- Удалена консоль опкодов из интерфейса, ручные команды остались доступны AI.
- Удалены предупреждения о работе только со своим самокатом.
- Сеть используется для AI-запросов и обновлений, для локальных AI-серверов разрешён cleartext HTTP.
- Обновления и релизы перенесены с Codeberg на GitHub.
- Версия 1.5.0 (8).

### Ограничения

- Проверка самоката и гарнитуры на реальном оборудовании не выполнена.
- Протокол Edifier зависит от модели, приложение использует стандартные GATT-операции и не содержит вымышленных команд.
- Release использует debug-подпись.

## 1.4.0 - 2026-10-23

### Добавлено

- Вкладка GATT с полным дампом сервисов и характеристик, копированием и переподключением.
- Диагностика рекламы BLE: service UUID, manufacturer data, raw.
- Расшифровка кодов GATT и повторный discovery перед выводом об отсутствии Nordic UART.
- Копирование всего журнала и отдельной строки по долгому нажатию.
- Автосохранение настроек без кнопки сохранения.
- Проверка обновлений GitHub, загрузка APK и установка через FileProvider.
- CI релизов по тегу vX.Y.Z: сборка APK, проверка подписи и публикация в GitHub.
- Индикатор состояния в шапке, обновленные списки устройств и пустые состояния.

### Изменено

- Удалены профили операторов, которые невозможно реализовать, вместе с экраном операторов и настройками.
- Устройства без Nordic UART помечаются в списке и не запускают автопереподключение.
- Версия 1.4.0 (7).

## 1.0.0 - 2026-10-18

### Добавлено

- Сканирование BLE, подключение по Nordic UART, MTU 247 и очередь записи.
- Рукопожатие 0x01 с ключом и сессионным ключом.
- Команды 0x05, 0x15, 0x61, 0x81, 0xA2, 0x54, 0x82, 0x91, 0x92, 0xC0, 0xFA.
- Телеметрия 0x31, 0x60, 0x63, 0x85 и 0x86.
- Спам разблокировки с временной меткой и foreground-сервисом.
- Консоль опкодов с каталогом из 54 команд.
- Демо-режим без Bluetooth.
- Пять тем: black, white, light, dark, amoled.
- Документация docs, analysis и references.
- Машиночитаемые opcodes.csv и frames.json.
- Проверка кадров verify_frames.py.
- Официальный base APK Urent 2.7.0 в references/apks через Git LFS.
- Манифесты, разрешения и компоненты шести приложений в manifests.json, permissions.csv и components.csv.
- Карта UUID в uuids.csv.
- Проверка references/validate_all.py.

### Исправлено

- sessionKey 0 больше не считается ошибкой.
- 0x10 разбирается как отклонённая команда и причина, а не как CRC.
- Очередь записи проверяет все чанки нового кадра и не переполняется.
- parseHex отклоняет не-ASCII цифры.
- Кадр GSM_AUTO_DETECT использует 0x53 вместо 0x83.

### Ограничения

- Нет hardware-теста.
- Release использует debug-подпись.
- Ключи 4BKNwi77 и w4S3Hqn5 не гарантированы.
- OTA не реализован.
