# Ошибки и статусы

## 1. 0x10 ERROR

Формат: payload[0] - команда, payload[1] - причина.

DanyUrent показывает:

- Самокат отклонил команду 0xNN;
- Самокат отклонил команду 0xNN, причина 0xMM;
- Самокат сообщил об ошибке без деталей.

NineHack дополнительно трактует payload[0]==1 как BUG CRC Bad. Это частный случай, который не используется как универсальная трактовка.

## 2. Авторизация

| Ситуация | Ответ | Действие |
| --- | --- | --- |
| payload[0]==1 | sessionKey=payload[1] | READY, authenticated=true |
| payload[0] не равен 1 | отказ | READY, authenticated=false |
| нет ответа 3 с | таймаут | READY, authenticated=false |
| sessionKey=0 | допустим | READY |
| запись не удалась | ошибка TX | READY |

Неверный ключ не блокирует приложение. Пользователь может повторить ввод.

## 3. Команды

| Команда | Успех | Неуспех |
| --- | --- | --- |
| 0x05 unlock | payload[0] 1 или 2 | иное или нет ответа |
| 0x15 lock | payload[0] 1 или 2 | иное или нет ответа |
| 0x61 set | payload[0] 0 | иное |
| 0x81 eject | payload[0] 1 | иное; LostBot g() считает 0 успехом |
| 0x54 clear BT | payload[0] | зависит от прошивки |
| 0x92 restart | ACK | нет ответа |
| 0x82 light | ACK | нет ответа |
| 0xC0 cover | ACK | нет ответа |
| 0x91 power | ACK | нет ответа |

Для 0x05 и 0x15 DanyUrent принимает коды 1 и 2. NineHack связывает 1 с успехом, а 2 может означать завершение операции. LostBot трактует 0 как OK, 1 как FAIL, 2 как ACK. Расхождение не разрешено без hardware-теста, поэтому в журнале возможен ложный отказ при успешной команде.

## 4. Прошивка

| Код 0xFB | Текст |
| --- | --- |
| 0 | ошибка ключа или пароля |
| 1 | устройство готово |
| 2 | передача завершена |
| 3 | таймаут приёма |
| 4 | ошибка CRC всего образа |
| иное | статус N |

DanyUrent не выполняет OTA, поэтому эти статусы носят информационный характер.

## 5. GATT и транспорт

| Сообщение | Причина |
| --- | --- |
| Bluetooth not supported | нет BLE-адаптера |
| Bluetooth disabled | адаптер выключен |
| Location services disabled | геолокация выключена до API 31 |
| BLE scanner unavailable | сканер недоступен |
| Scan failed: N | ошибка ScanCallback |
| Scan permission denied | отозвано разрешение |
| Connect permission denied | отозвано BLUETOOTH_CONNECT |
| Connection timeout | нет подключения за 20 с |
| GATT status 133 | сбой стека |
| UART service not found | нет сервиса |
| UART characteristics not found | нет характеристики |
| Failed to enable notifications | ошибка setCharacteristicNotification |
| Notification descriptor write failed | ошибка CCCD |
| Notification setup timeout | CCCD не ответил за 3 с |
| Write failed: N | ошибка записи |
| BLE write timeout | нет onCharacteristicWrite за 2 с |
| BLE write queue overflow | больше 64 чанков |

## 6. Приложение

| Сообщение | Значение |
| --- | --- |
| Требуется авторизация | команда вызвана без sessionKey |
| Нет подключения | isConnected=false |
| Сначала авторизуйтесь | спам без READY |
| Не удалось отправить кадр | транспорт вернул false |
| Переполнение буфера приёма | rxBuffer больше 1024 байт |
| Ошибка CRC на самокате | устаревшая трактовка 0x10, заменена |
| Настройки не применены | 0x61 вернул не 0 |
| Ошибка разблокировки | 0x05 вернул не 1 и не 2 |
| Ошибка блокировки | 0x15 вернул не 1 и не 2 |
| Ошибка изъятия батареи | 0x81 вернул не 1 |

## 7. Классификация

- Восстановимые: таймаут авторизации, неверный ключ, занятый GATT, временный разрыв.
- Требуют действий: разрешения, Bluetooth, геолокация, неверный адрес.
- Требуют другого ключа: отказ 0x01.
- Требуют проверки протокола: 0x10, неизвестный опкод, неожиданный payload.
- Опасные: 0x81, 0x91, 0x92, OTA.

## 8. Что не реализовано

- Расшифровка причин 0x10.
- Повтор команды при таймауте.
- Разделение ошибок записи и ошибок протокола.
- Экспорт диагностики.
- Уведомление о критической ошибке.
