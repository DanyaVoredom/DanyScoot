# Экраны референсов

## 1. LostBot

Основные экраны:

- главный экран со списком устройств;
- управление самокатом;
- журнал;
- настройки;
- экран подписки и активации;
- экран прошивки;
- экран ключей BLE.

Элементы управления:

- подключение и отключение;
- разблокировка и блокировка;
- спам;
- изъятие батареи;
- поиск;
- настройки света и режима;
- телеметрия;
- RFID;
- прошивка.

Настройки:

- интервал спама;
- автовозобновление;
- автопереподключение;
- показ всех устройств;
- журнал сканирования;
- демо-режим;
- тема.

LostBot использует foreground-сервис для спама и показывает уведомление с кнопкой остановки.

## 2. FishBot

Визуально повторяет LostBot. Отличия:

- дополнительные диалоги плагина;
- экран активации;
- remote share dialog;
- возможные кнопки установки и VPN.

Инжектор не работает как shipped, поэтому часть экранов может быть недоступна.

## 3. NineHack

Экраны:

- mainActivity: Settings, название, версия, Start;
- permissionsActivity: запрос разрешений;
- scanActivity: список BLE-устройств, скан 10 секунд;
- bleSettingsActivity: ввод ключа;
- controlActivity: вкладки управления и журнал.

Управление:

- разблокировать;
- заблокировать;
- изъять батарею;
- режим;
- фара;
- газ;
- применить.

Ответы и ошибки выводятся в TextView с автопрокруткой. Нет телеметрии, прошивки и сети.

## 4. Urent

Официальное приложение:

- карта;
- список транспорта;
- карточка самоката;
- сканирование QR;
- оплата;
- история;
- поддержка;
- профиль;
- push-уведомления.

BLE-экранов нет. Разблокировка выполняется серверным запросом.

## 5. DanyUrent

Четыре вкладки:

- Устройства;
- Управление;
- Журнал;
- Настройки.

Отличия от LostBot:

- проще структура;
- пять тем;
- демо-режим;
- каталог опкодов;
- консоль;
- нет подписки, сети и прошивки;
- нет истории и карт.

Подробное описание: docs/ui.md.

## 6. Сравнение UX

| Принцип | LostBot | NineHack | DanyUrent |
| --- | --- | --- | --- |
| Порог входа | высокий | средний | средний |
| Подключение | скан и список | скан и список | скан и список |
| Авторизация | автоматическая константой | ручной ключ | ручной ключ |
| Телеметрия | да | нет | да |
| Опасные команды | без подтверждения | без подтверждения | без подтверждения |
| Спам | да | нет | да |
| Демо | да | нет | да |
| Темы | нет | нет | да |

## 7. Выводы

- LostBot даёт наиболее полный набор функций, но перегружен сетью и лицензией.
- NineHack минимален и удобен для понимания протокола.
- Urent не использует BLE и не может быть UI-ориентиром для BLE-команд.
- DanyUrent занимает промежуточное положение: больше функций, чем NineHack, меньше, чем LostBot.
