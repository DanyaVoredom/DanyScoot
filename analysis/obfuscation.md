# Обфускация и упаковка

## 1. Сводка

| Приложение | Упаковщик | Обфускация | Отладочные артефакты | Риск |
| --- | --- | --- | --- | --- |
| LostBot | нет явного | R8 или ProGuard, короткие имена | baseline.prof | средний |
| FishBot | com.px, mirrorb, cloudinject, sadfxg | StringFog, control-flow flattening | payload-плагин | высокий |
| NineHack | нет | минимальная | Crashlytics, dump_syms, debuggable | низкий |
| Urent | нет явного | коммерческая, R8 | аналитика и push | средний |
| DanyUrent | нет | minify выключен | нет | низкий |

## 2. LostBot

- Классы имеют короткие имена: A2/c, A2/f, C2/F, z2/i.
- Это результат R8 или ProGuard.
- Строки и константы читаемы.
- Ключ w4S3Hqn5 собирается из массива в z2/l.java и используется в DI-провайдере.
- Нет StringFog.
- Есть baseline-профили.

Код пригоден для анализа после jadx. Часть методов не декомпилируется, тогда используется smali.

## 3. FishBot

Признаки упаковщика:

- com/sadfxg/fasg/App;
- com/px, 306 файлов;
- com/cloudinject, 30 файлов;
- mirrorb, 421 файл;
- cd, 1076 файлов;
- org/lsposed/hiddenapibypass, 12 файлов.

StringFog:

- сообщения Stringfog implementation class not found, access, new instance failed;
- константы u06xx в App.smali являются ключами диспетчеризации, а не полезной нагрузкой.

Control-flow flattening:

- sparse-switch;
- разбиение методов на блоки;
- усложняет чтение, но не меняет поведение.

Инжектор нерабочий:

- компоненты com.px и com.cloudinject не объявлены в манифесте;
- пакеты core и plugincore отсутствуют;
- launcher плагина отсутствует;
- android.support.v7 отсутствует;
- payload-ассет есть, но UI собрать нечем.

Вывод: упаковщик и туннель присутствуют, полезная нагрузка не активируется как shipped. Это не делает APK безопасным.

## 4. NineHack

- Манифест debuggable=true.
- Нет R8-обфускации приложения.
- Классы называются controlActivity, CommandCreator, bleSettingsActivity.
- Внутри около 8.6 МБ из 11.0 МБ занимает отладочный инструментарий Crashlytics, dump_syms для Linux, macOS и Windows, DebugProbesKt.bin, LICENSES.txt, public-suffix-list.
- app-metadata.properties: appMetadataVersion=1.1, AGP 8.5.0.

Это облегчает анализ, но указывает на небрежную сборку. Публиковать такое приложение нельзя.

## 5. Urent

- Официальная коммерческая сборка.
- Множество модулей и SDK.
- R8 и удаление неиспользуемого кода вероятны, но не подтверждены детально.
- Appsflyer, Yandex Metrica, MTS, Pushwoosh, Huawei, Firebase.
- BLE-классов нет, поэтому обфускация не мешает выводу об отсутствии BLE.

## 6. DanyUrent

- minifyEnabled=false.
- Нет R8.
- Нет обфускации.
- Код читаем.
- Нет отладочных библиотек.
- Release использует debug-подпись.

Для публичной сборки рекомендуется включить R8, удалить отладочные логи и маскировать ключ.

## 7. Методы анализа

- apktool 3.0.3 для ресурсов и smali.
- jadx 1.5.6 для Java.
- Поиск по строкам и UUID.
- Сравнение хешей классов.
- Проверка манифеста.
- Проверка подписи apksigner.

## 8. Ограничения

- Обфускация может скрывать не только код, но и данные.
- Отсутствие строки не доказывает отсутствие функции.
- Наличие упаковщика не доказывает вредоносность.
- Наличие VPN-кода не доказывает активный C2.
- Для точных выводов нужен динамический анализ в изолированной среде.
