# Ограничения и неизвестные

## 1. Аппаратные

- Нет физического самоката.
- Нет телефона с BLE в среде разработки.
- BlueStacks не поддерживает BLE.
- Нет HCI snoop лога реального сценария.
- Нет UART-доступа к модулю.
- Нет дампа прошивки.

Следствие: ни одна BLE-команда не проверена на реальном устройстве.

## 2. Ключи

- Неизвестно, работают ли 4BKNwi77 и w4S3Hqn5 на конкретной прошивке.
- Неизвестно, зависит ли ключ от партии, модели или сервера.
- Неизвестно, требуется ли ровно 8 байт.
- Нет способа извлечь ключ из официального Urent 1.90.2 и 2.7.0.
- Нет подтверждения, что ключ LostBot не отозван.

## 3. Команды

- Две формы 0x05 не проверены.
- Статусы 0x05 и 0x15 противоречивы: LostBot считает 0 успехом, 1 ошибкой, 2 подтверждением; NineHack связывает 1 с успехом. DanyScoot принимает 1 и 2.
- Статус 0x81 противоречив: NineHack ожидает 1, LostBot g() считает 0 успехом. DanyScoot ожидает 1.
- Неизвестно, какие команды поддерживает конкретная модель.
- Неизвестно, требуется ли время в 0x05 всегда или только для спама.
- Неизвестно, влияет ли режим на 0x61.
- Неизвестно, что означает payload 0x10 на разных прошивках.
- Неизвестны единицы и диапазоны телеметрии для всех моделей.
- Неизвестно, можно ли безопасно использовать 0x91 и 0x92.

## 4. Прошивка

- Формат OTA восстановлен по клиенту, не по серверу.
- Нет образа прошивки.
- Нет ключа передачи.
- Нет проверки CRC16 на реальном образе.
- Нет процедуры восстановления.
- Нет подтверждения, что 0xFB принимает произвольный образ.

## 5. Сеть

- Официальный API не документирован публично.
- Неофициальный OpenAPI может расходиться с APK.
- Нет проверки подписи ur-request-data.
- Нет данных о серверной логике openlock.
- Нет доступа к аккаунту Urent.
- FishBot C2 не подтверждён.

## 6. UI

- Нет пользовательских исследований.
- Нет проверки на планшетах и складных устройствах.
- Нет проверки TalkBack.
- Нет проверки всех тем на реальном экране.
- Нет локализации.
- Нет подтверждения для опасных команд.

## 7. Тесты

- Нет instrumentation-тестов.
- Нет тестов BleTransport.
- Нет тестов ScooterClient.
- Нет fuzzing.
- Нет CI.
- Нет проверки на разных API.

## 8. Безопасность

- Ключ хранится в открытом виде.
- Ключ попадает в журнал.
- Нет шифрования BLE.
- Нет защиты от replay.
- Нет проверки устройства.
- Release подписан debug-ключом.
- Нет политики конфиденциальности.

## 9. Юридические

- Использование на чужом самокате запрещено.
- Обход аренды запрещён.
- Нет проверки местных законов.
- Нет соглашения с оператором.
- Товарные знаки принадлежат владельцам.

## 10. Что считается установленным

- Официальное Urent 1.90.2 и 2.7.0 не содержит BLE-стека.
- LostBot и NineHack используют A3 A4, CRC8 и Nordic UART.
- Ключи 4BKNwi77 и w4S3Hqn5 присутствуют в референсах.
- 0x01 возвращает статус и sessionKey.
- 0x10 содержит отклонённую команду и причину.
- 0x05 имеет две формы.
- 0xFA, 0xFB и 0xFC относятся к прошивке.
- DanyScoot не имеет сети.

## 11. Что нельзя утверждать

- Что приложение работает на любом самокате Urent.
- Что ключи универсальны.
- Что спам безопасен.
- Что OTA-формат подходит для всех моделей.
- Что официальный API совпадает с OpenAPI.
- Что FishBot содержит рабочий C2.
- Что DanyScoot обходит серверные ограничения.
