# FusionBot

Комбинированное Android-приложение на базе трёх референсов из каталога references: FishBot (сборка LostBot), LostBot и NineHack. Реализует полный протокол LostBot (кадры A3 A4, CRC-8, каталог опкодов, спам разблокировки, декодеры телеметрии) и семантику команд NineHack (ключ, разблокировка, блокировка, установка параметров, изъятие батареи), плюс демо-режим для проверки без самоката.

## Сборка

```
cd app
gradlew.bat --no-daemon assembleDebug
```

Готовый APK: app\build\outputs\apk\debug\app-debug.apk

Параметры: Gradle 8.14.3, AGP 8.11.1, Kotlin 2.2.0, compileSdk 36, minSdk 23, targetSdk 35, JDK 17.

## Тесты

```
cd app
gradlew.bat --no-daemon testDebugUnitTest
```

Покрыты формат кадра, генерация rand, CRC8 (контрольное значение 0xA1), XOR полей, сборка всек команд, раскладка спам-кадра, декодеры телеметрии, RFID и разбор hex.

## Возможности

- Сканирование BLE, фильтр по сервисному UUID Nordic UART, показ RSSI, поиск по всем устройствам при включённой опции.
- Подключение, запрос MTU 247, включение нотификаций, запись чанками по MTU-3 с последовательной очередью.
- Авторизация ключом (команда 0x01), сессионный ключ из ответа, таймаут 3000 мс.
- Разблокировка (0x05), блокировка (0x15), изъятие батареи (0x81), сигнал (0xA2), установка фары, режима и газа (0x61).
- Спам разблокировки: кадр 0x05 с отметкой времени в секундах, интервал 20..10000 мс, foreground-сервис с уведомлением и кнопкой остановки, счётчик отправок, автовозобновление после переподключения.
- Телеметрия: команда 0x31 (версия, флаг лока, напряжение), 0x60 (батарея, режим, скорость, пробег, запас хода), 0x63 (батарея, скорость, ток, флаги), 0x85 и 0x86 (RFID).
- Консоль ручных команд: выбор опкода из каталога, произвольный hex-payload.
- Сервисные команды: крышка батареи (0xC0), перезапуск IoT (0x92), очистка привязанных BT (0x54), подсветка RGB (0x82), управление питанием (0x91), чтение конфига IoT (0xFA).
- Журнал обмена с уровнями TX, RX, INFO, OK, WARN, ERR и автопрокруткой.
- Настройки: ключ BLE с пресетами NineHack (4BKNwi77) и LostBot (w4S3Hqn5), интервал спама, автоподключение с числом попыток и задержкой, журнал сканирования, фильтр каталога опкодов, демо-режим.
- Демо-режим: виртуальный самокат с растущей скоростью, ответами на команды и полной телеметрией, Bluetooth не требуется.

## Структура

```
app/app/src/main/java/com/dany/fusionbot/
  App.kt                  инициализация
  MainActivity.kt         вкладки, разрешения, статус
  ble/Frame.kt            кадр A3 A4, CRC8, CRC16, hex
  ble/ScooterCodec.kt     сборка команд и разбор ответов
  ble/BleTransport.kt     GATT: скан, подключение, MTU, запись, нотификации
  ble/OpcodeCatalog.kt    каталог опкодов LostBot
  core/ScooterClient.kt   состояние, рукопожатие, спам, декодирование
  core/Prefs.kt           настройки
  core/LogBus.kt          журнал
  spam/SpamService.kt     foreground-сервис спама
  ui/                     фрагменты: устройства, управление, журнал, настройки
```

## Ограничение

Приложение предназначено для работы только с собственным самокатом. Использование на чужих устройствах без разрешения владельца незаконно.
