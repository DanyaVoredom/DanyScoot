# Urent BLE probe

Инструмент для проверки протокола A3 A4 на своем самокате. Проверяет гипотезы, которые нельзя подтвердить по APK: обязательна ли авторизация, принимает ли прошивка команду с чужим session key, можно ли повторить записанный кадр.

Те же проверки bypass и brute доступны в Android-приложении через AI-инструменты, поэтому телефон можно использовать без ПК. Python-вариант нужен для ноутбука с BLE и для режимов capture и replay.

## Откуда брать статический ключ

Ключ A3 A4 не шифруется, а только XOR-ится с rand. Поэтому его видно в HCI-логе любого клиента, который успешно авторизуется на самокате.

1. Включить на телефоне Bluetooth HCI snoop log в меню разработчика.
2. Перезапустить Bluetooth, подключиться рабочим BLE-клиентом и выполнить авторизацию.
3. Снять bugreport или достать btsnoop_hci.log.
4. Разобрать лог:

```
python tools/hci_extract.py btsnoop_hci.log
```

Скрипт печатает статический ключ из кадра 0x01 и session key из ответа. Если официальное приложение оператора не использует BLE, лог нужно снимать с клиента, который реально открывает замок по BLE.

Другие источники:

- дамп прошивки через UART, SWD или SPI-флеш, поиск ASCII-строки ключа рядом с обработчиком A3 A4;
- APK сторонних клиентов, строки и нативные библиотеки;
- ответ сервера, если оператор отдает BLE-ключ через API;
- форумы и чаты, но такие ключи требуют проверки.

Ключ обычно относится к семейству прошивки, а не к каждому самокату. Session key меняется при подключении и приходит в ответе на auth.


Установка зависимости:

```
python -m pip install bleak
```

Сканирование:

```
python tools/urent_probe.py --scan
```

Авторизация известными ключами и разблокировка:

```
python tools/urent_probe.py --address AA:BB:CC:DD:EE:FF --mode auth --unlock
```

Обход авторизации, отправка unlock с key 0 и key 0x42:

```
python tools/urent_probe.py --address AA:BB:CC:DD:EE:FF --mode bypass
```

Перебор однобайтового session key 0..255:

```
python tools/urent_probe.py --address AA:BB:CC:DD:EE:FF --mode brute --gap 0.05
```

Запись входящих кадров:

```
python tools/urent_probe.py --address AA:BB:CC:DD:EE:FF --mode capture --seconds 30
```

Повтор кадра:

```
python tools/urent_probe.py --address AA:BB:CC:DD:EE:FF --mode replay --hex "A3 A4 ..."
```

Режимы bypass и brute экспериментальные. Прошивка может требовать успешный auth до любых команд, тогда перебор session key не сработает.
