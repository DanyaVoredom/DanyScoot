# Планы

## 1. Ближайшие задачи

- Провести hardware-тест на совместимом самокате.
- Проверить гарнитуру Edifier: батарею, Device Information, 1101, 1102, 1103.
- Зафиксировать результаты в analysis/hardware_test.md.
- Проверить обе формы команды 0x05 на разных прошивках.
- Проверить набор команд 0x31, 0x60, 0x63, 0x85.
- Проверить AI с OpenAI, Anthropic и локальным сервером.
- Добавить instrumentation-тест для BleTransport.
- Добавить тесты ScooterClient с фейковым транспортом.
- Добавить fuzz-тест FrameCodec.findFrames.
- Маскировать поле BLE-ключа в настройках.
- Добавить подтверждение для опасных команд.
- Добавить постоянную release-подпись.

## 2. Улучшения протокола

- Профиль команд NineHack и LostBot с явным выбором.
- Автоматический выбор формы 0x05 по ответу самоката.
- Повтор команды при отсутствии ответа.
- Очередь команд с таймаутами.
- Разбор всех 54 опкодов.
- Чтение и отображение версии прошивки.
- Проверка модели по ответу 0x31.
- Поддержка 0x82 с выбором цвета.
- Поддержка 0x91 с подтверждением.
- Диагностика 0x10 с расшифровкой причин.

## 3. Улучшения UI

- Экран диагностики с последовательностью шагов.
- График скорости и тока.
- История журнала с экспортом.
- Поиск и фильтры журнала.
- Сохранение истории AI-чата между запусками.
- Выбор профиля GATT вручную для универсальных устройств.
- Тёмная и светлая темы по системной настройке.
- Улучшение доступности: contentDescription, размеры, контраст.
- Локализация на английский.
- Экран с объяснением разрешений.
- Инструкция по подключению внутри приложения.
- Настройка профиля протокола.

## 4. Безопасность

- Шифрование BLE-ключа и API-ключа AI через Android Keystore.
- Маскирование ключей в UI.
- Удаление ключей из logcat.
- Отключение cleartext HTTP по умолчанию.
- Ограничение частоты попыток.
- Проверка адреса и имени устройства.
- Предупреждение при подключении к незнакомому устройству.
- Политика конфиденциальности.
- Отключение экспорта журнала по умолчанию.

## 5. Инфраструктура

- CI для unit-тестов и lint.
- Проверка ссылок в документации.
- Генерация opcode_reference.md из CSV.
- Проверка схемы frames.json.
- Подпись release в CI.
- Автоматическая сборка APK.
- Версионирование документации.

## 6. Не-цели

- Обход серверной аренды Urent.
- Подключение к чужому транспорту.
- Массовый подбор ключей.
- Атаки на серверы.
- Обновление прошивки без проверенных данных.
- Передача BLE-ключа в AI-сервер.
- Поддержка iOS.
- Публикация в магазине без юридической проверки.

## 7. Критерии приоритета

Приоритет выше, если:

- повышает безопасность;
- уменьшает риск кирпича или потери данных;
- подтверждён данными из APK;
- улучшает диагностику;
- не требует догадок о протоколе.

Приоритет ниже, если:

- требует hardware, которого нет;
- меняет поведение без подтверждения;
- добавляет сеть или разрешения;
- дублирует существующие данные.
