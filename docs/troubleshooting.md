# Диагностика

## 1. Быстрая таблица

| Симптом | Вероятная причина | Действие |
| --- | --- | --- |
| Скан не находит устройств | нет разрешений, Bluetooth выключен, геолокация выключена | проверить разрешения и системные настройки |
| Устройство есть, но подключение не начинается | неверный адрес или GATT занят | перезапустить Bluetooth, выбрать устройство заново |
| UART service not found | другое устройство или другой UUID | проверить тип устройства и сервис |
| Гарнитура подключается, но команд нет | для внешнего устройства команды самоката недоступны | использовать GATT-инструменты и чтение данных |
| AI не отвечает | неверный URL, ключ или формат | проверить настройки AI и журнал |
| Connection timeout | устройство вне зоны, занято другим клиентом | перезапустить самокат, повторить |
| GATT status 133 | сбой стека Android | закрыть другие BLE-приложения, перезапустить Bluetooth |
| Таймаут авторизации | ключ неверный или самокат не отвечает | проверить ключ, повторить |
| Неверный ключ | ключ не подходит | попробовать другой пресет |
| READY, но кнопки неактивны | authenticated=false | выполнить авторизацию заново |
| Команда отклонена | самокат не поддерживает опкод или состояние | проверить 0x10 и журнал |
| Спам не запускается | нет авторизации | подключиться и авторизоваться |
| Спам остановился | потеря связи или остановка сервиса | проверить журнал и настройки |
| Нет уведомления спама | нет POST_NOTIFICATIONS | выдать разрешение |
| Тема не меняется | Activity не пересоздалась | повторить выбор или перезапустить |
| APK не устанавливается | другая подпись или старая версия | удалить приложение |

## 2. Разрешения

Android 12 и выше:

- BLUETOOTH_SCAN;
- BLUETOOTH_CONNECT;
- POST_NOTIFICATIONS на Android 13 и выше.

Android 11 и ниже:

- ACCESS_FINE_LOCATION;
- ACCESS_COARSE_LOCATION;
- BLUETOOTH;
- BLUETOOTH_ADMIN.

Если разрешение отозвано после запуска, скан завершится ошибкой Scan permission denied. Проверить:

```
adb shell dumpsys package ru.dany.scoot | Select-String BLUETOOTH
```

## 3. Bluetooth выключен

Приложение проверяет адаптер перед сканированием и подключением. Сообщение Bluetooth disabled означает, что адаптер выключен или недоступен.

Действия:

1. Включить Bluetooth в системных настройках.
2. Отключить режим полёта.
3. Перезапустить Bluetooth.
4. Перезапустить приложение.

## 4. Геолокация

На Android 11 и ниже сканирование BLE требует включённой геолокации даже при разрешении ACCESS_FINE_LOCATION. Сообщение Location services disabled означает, что геолокация выключена.

На Android 12 и выше используется neverForLocation, поэтому геолокация не требуется. Если производитель прошивки игнорирует флаг, может потребоваться включить геолокацию вручную.

## 5. Устройство не найдено

Проверить:

- самокат включён;
- BLE-модуль активен;
- устройство не подключено к другому телефону;
- фильтр UART не скрывает устройство;
- включён показ всех устройств;
- скан не остановлен через 15 секунд.

Если устройство видно в nRF Connect, но не в DanyScoot, проверить сервисный UUID. Если не видно нигде, проблема на стороне самоката или телефона.

## 6. Ошибка профиля

Сообщение UART service not found означает, что GATT подключился, но сервис 6e400001-b5a3-f393-e0a9-e50e24dcca9e не найден и авто-профиль не смог выбрать пару характеристик. Для Edifier проверяется сервис 00001100-d102-11e1-9b23-00025b00a5a5. Возможные причины:

- выбрано не то устройство;
- самокат использует другой сервис;
- сервис скрыт до авторизации;
- прошивка требует другого порядка обнаружения;
- в устройстве нет одновременно writable и notifiable характеристики в одном сервисе.

Действия:

1. Подключиться через nRF Connect.
2. Посмотреть список сервисов.
3. Сравнить UUID.
4. Зафиксировать результат в analysis/hardware_test.md.

## 7. Таймаут подключения

Таймаут 20 секунд. Причины:

- устройство выключено;
- устройство занято другим центральным устройством;
- слабый сигнал;
- зависший GATT-стек.

Действия:

1. Перезапустить самокат.
2. Отключить другие BLE-клиенты.
3. Перезапустить Bluetooth на телефоне.
4. Повторить подключение.

## 8. GATT 133

Код 133 означает общий сбой GATT. Приложение закрывает GATT с задержкой 150 мс и сообщает об ошибке.

Действия:

1. Закрыть приложения, которые держат BLE.
2. Выключить и включить Bluetooth.
3. Перезагрузить телефон.
4. Повторить.

Если ошибка повторяется на конкретном телефоне, проверить на другом.

## 9. Таймаут авторизации

Через 3000 мс после отправки ключа приложение сообщает Таймаут авторизации. Причины:

- неверный ключ;
- самокат не поддерживает 0x01;
- notify не включён;
- кадр не дошёл;
- прошивка ожидает другую длину ключа.

Действия:

1. Проверить ключ в настройках.
2. Попробовать пресет NineHack.
3. Попробовать пресет LostBot.
4. Посмотреть журнал TX и RX.
5. Проверить, приходят ли любые notify.
6. Проверить HCI snoop.

## 10. Неверный ключ

Ответ 0x01 с payload[0] не равен 1 означает отказ. Приложение показывает Неверный ключ и остаётся в READY.

Проверить:

- ключ без пробелов;
- регистр символов;
- длину;
- что используется нужный самокат.

Ключ 4BKNwi77 и w4S3Hqn5 не универсальны. Если ключ отклонен, приложение автоматически пробует второй известный ключ и запоминает рабочий. Если оба не подходят, нужен дамп прошивки, HCI-лог официального клиента или другой источник.

## 11. Команда не выполняется

Проверить журнал:

- TX: кадр ушёл;
- RX: пришёл ответ;
- 0x10: самокат отклонил команду;
- нет RX: команда не дошла или ответ не пришёл.

Типичные причины:

- неверный sessionKey;
- команда не поддерживается прошивкой;
- неверный payload;
- самокат в состоянии, запрещающем команду;
- очередь записи переполнена.

Для диагностики использовать AI-инструмент send_raw_command и повторять команду с известным payload из references/frames.json. Для внешнего устройства доступны read_characteristic, write_characteristic и subscribe_characteristic.

## 12. Спам

Спам требует isReady=true. Если кнопка не запускается, сначала выполнить авторизацию.

При активном спаме:

- foreground-уведомление обязательно;
- без POST_NOTIFICATIONS на Android 13+ уведомление может не появиться;
- сервис может быть остановлен системой при нехватке памяти;
- при потере связи спам останавливается;
- автовозобновление включается только настройкой autoResumeSpam.

Если счётчик не растёт, проверить writeFrame и очередь. Если счётчик растёт, но самокат не реагирует, проверить форму 0x05 и sessionKey.

## 13. Журнал

Журнал ограничен 1000 строк. При интенсивном спаме старые строки быстро вытесняются. Для длительной диагностики лучше использовать logcat или HCI snoop.

```
adb logcat -s BLE AUTH SPAM SCOOTER FW INFO
```

Ключ и кадры могут попадать в logcat. Не публиковать логи без очистки.

## 14. AI

Если чат не отвечает:

1. Проверить base URL, ключ и модель в настройках.
2. Для OpenAI указать https://api.openai.com/v1, для Anthropic https://api.anthropic.com/v1.
3. Оставить формат Авто или выбрать явно, если сервер использует нестандартный путь.
4. Проверить журнал: ошибка HTTP содержит код и начало ответа сервера.
5. Для локального сервера без TLS разрешён cleartext HTTP.

Если AI отвечает, но не управляет устройством, проверить, что устройство подключено и инструмент вернул ошибку. Команды самоката блокируются для гарнитуры и внешних устройств.

## 15. Сборка

Если Gradle не видит SDK:

1. Проверить app/local.properties.
2. Проверить ANDROID_HOME.
3. Открыть проект в Android Studio.
4. Выполнить sync.

Если JDK неверный:

```
java -version
```

Нужен JDK 17. JAVA_HOME должен указывать на него.

## 16. Что приложить к отчёту об ошибке

- модель телефона и версия Android;
- модель самоката или гарнитуры и версия прошивки;
- ключ, если он не секретный;
- шаги воспроизведения;
- журнал без персональных данных;
- HCI snoop, если возможно;
- результат nRF Connect;
- версия DanyScoot.
