# Интерфейс

## 1. Структура

Основной экран содержит нижнюю навигацию из пяти вкладок:

- Устройства;
- Управление;
- GATT;
- Лог;
- Настройки.

Сверху отображается цветной индикатор, имя подключённого устройства, состояние и кнопка AI. При активном спаме появляется badge с числом отправленных кадров. Кнопка AI открывает отдельный экран чата, потому что нижняя навигация ограничена пятью вкладками.

Цвета индикатора:

- серый: нет подключения;
- жёлтый: скан, подключение, discovery или авторизация;
- зелёный: готово;
- красный: ошибка.

Фрагменты создаются один раз и скрываются через FragmentTransaction. Состояние вкладки сохраняется при повороте экрана.

## 2. Устройства

Элементы:

- кнопка сканирования или остановки;
- кнопка сортировки;
- список устройств с именем, адресом, RSSI, примерным расстоянием, меткой типа и данными рекламы;
- подпись с числом найденных устройств;
- пустое состояние с подсказкой.

Поведение:

- скан длится 15 секунд;
- сортировка по умолчанию по расстоянию, также доступны имя, адрес и тип;
- устройства с именем Unknown скрываются по настройке;
- устройства без Nordic UART и Edifier показываются по настройке;
- адреса, на которых discovery не нашёл профиль, помечаются красной рамкой до успешного подключения;
- нажатие на устройство запускает подключение с определённым типом и переключает на вкладку Управление.

## 3. Управление

Блок подключения:

- поле ключа;
- кнопка авторизации;
- кнопка подключения к последнему устройству;
- кнопка отключения;
- строка состояния.

Основные команды:

- разблокировать;
- заблокировать;
- изъять батарею;
- найти самокат;
- применить настройки.

Настройки самоката:

- переключатель фары;
- три режима движения;
- переключатель газа;
- кнопка применения.

Спам:

- поле интервала;
- кнопка запуска;
- кнопка остановки;
- счётчик отправок и признак активности.

Телеметрия:

- батарея;
- скорость;
- пробег;
- запас хода;
- версия;
- напряжение;
- признак блокировки;
- кнопка обновления.

Сервисные команды:

- крышка батареи;
- перезапуск IoT;
- очистка Bluetooth;
- RGB-подсветка;
- питание;
- чтение конфига.

Гарнитура и внешнее устройство:

- батарея;
- прошивка;
- модель;
- производитель;
- кнопка чтения данных.

Для внешнего устройства блоки ключа, замка, самоката, сервисов и телеметрии скрываются. Ручные команды доступны через AI-инструменты.

Кнопки команд недоступны, пока isReady=false. Это предотвращает отправку кадров без сессионного ключа.

## 4. GATT

Экран показывает полный список сервисов и характеристик, который вернуло устройство.

Элементы:

- карточка с именем устройства, адресом, числом сервисов и характеристик;
- список сервисов с полным UUID, коротким UUID и свойствами характеристик;
- кнопка копирования дампа в буфер обмена;
- кнопка переподключения к последнему устройству.

Дамп публикуется после каждого discovery. Если профиль Nordic UART или Edifier отсутствует, в журнале появляется тег GATT с подсказкой, а для внешних устройств включается авто-профиль. Список сервисов сохраняется после отключения, чтобы его можно было скопировать.

## 5. Лог

Журнал показывает строки с временем, уровнем, тегом и текстом. Уровни:

- INFO: обычные события;
- TX: отправленные кадры;
- RX: принятые кадры;
- OK: успешные операции;
- WARN: отклонённые команды;
- ERR: ошибки.

Есть автопрокрутка, копирование всего журнала, копирование строки по долгому нажатию и очистка. Журнал хранится в памяти и ограничен 1000 строками.

## 6. Настройки

Блоки:

- тема;
- ключ BLE и пресеты NineHack и LostBot;
- интервал спама;
- автовозобновление спама;
- автопереподключение, число попыток и задержка;
- показ всех устройств;
- скрытие Unknown;
- журнал сканирования;
- сортировка устройств;
- AI: base URL, API-ключ, модель, формат, открытие чата;
- проверка обновлений и установка APK;
- версия приложения.

Изменения сохраняются автоматически, кнопки сохранения нет. Числовые поля ограничиваются при потере фокуса. Смена темы пересоздаёт Activity. Выключение автопроверки не удаляет уже скачанный APK.

## 7. AI

Экран AI открывается кнопкой в шапке или из настроек. Содержит историю сообщений, поле ввода, кнопки отправки и остановки, очистку истории и строку текущего инструмента.

Поддерживаются OpenAI Chat Completions, OpenAI Responses и Anthropic Messages. Формат Авто определяется по base URL: anthropic или messages, responses, иначе chat completions. AI вызывает инструменты приложения: скан, подключение, GATT, чтение и запись, команды самоката, настройки, журнал, обновления, навигацию и операции Edifier. Опасные действия выполняются только по явной просьбе.

## 8. Обновления

- Автопроверка выполняется при запуске не чаще раза в сутки.
- Источник: последний релиз GitHub с APK-ассетом.
- Версия из тега сравнивается с versionName.
- APK скачивается в кэш и устанавливается через FileProvider.
- На Android 8+ требуется разрешение на установку из этого источника.
- Кнопка проверки вручную запускает ту же цепочку и после загрузки меняется на установку.

## 9. Состояния

| Состояние | Текст | Доступность команд |
| --- | --- | --- |
| IDLE | Отключено | нет |
| SCANNING | Сканирование | нет |
| CONNECTING | Подключение | нет |
| DISCOVERING | Обнаружение сервисов | нет |
| AUTHENTICATING | Авторизация | нет |
| READY | Готово | да, если ключ принят или устройство внешнее |
| ERROR | Ошибка | нет |

При неверном ключе состояние READY, но authenticated=false. Строка состояния может выглядеть готовой, однако кнопки остаются отключёнными. Повторная авторизация выполняется кнопкой ключа.

## 10. Доступность

- Все кнопки имеют текстовые подписи.
- Размер интерактивных элементов соответствует Material 3.
- Темы проверяются на контраст.
- Горизонтальная прокрутка не используется, кроме длинных строк журнала.
- Клавиатура не перекрывает поля ввода благодаря adjustResize.
- Поддержка RTL включена, но тексты только русские.

## 11. Ограничения UI

- Нет экрана истории или графика телеметрии.
- Нет подтверждения для опасных команд, включая изъятие батареи и питание.
- Нет поиска по журналу.
- Нет экспорта журнала в файл.
- Нет выбора профиля команд NineHack или LostBot.
- Нет инструкции по подключению внутри приложения.
- История AI-чата хранится только в памяти процесса.

Эти ограничения перечислены в docs/roadmap.md.
