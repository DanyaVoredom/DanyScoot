# Интерфейс

## 1. Структура

Основной экран содержит нижнюю навигацию из пяти вкладок:

- Устройства;
- Управление;
- GATT;
- Лог;
- Настройки.

Сверху отображается цветной индикатор, имя подключённого устройства и состояние. При активном спаме появляется badge с числом отправленных кадров.

Цвета индикатора:

- серый: нет подключения;
- жёлтый: скан, подключение, discovery или авторизация;
- зелёный: готово;
- фиолетовый: демо-режим;
- красный: ошибка.

Фрагменты создаются один раз и скрываются через FragmentTransaction. Состояние вкладки сохраняется при повороте экрана.

## 2. Устройства

Элементы:

- кнопка сканирования или остановки;
- кнопка демо-режима или отключения;
- список устройств с именем, адресом, RSSI, меткой UART и данными рекламы;
- подпись с числом найденных устройств;
- пустое состояние с подсказкой.

Поведение:

- скан длится 15 секунд;
- при включённом фильтре UART показываются только устройства с сервисным UUID;
- при отключённом фильтре показываются все BLE-устройства;
- устройства без Nordic UART помечаются красной меткой и рамкой;
- адреса, на которых discovery не нашёл UART, остаются помеченными до успешной авторизации;
- нажатие на устройство запускает подключение и переключает на вкладку Управление;
- демо-режим не требует Bluetooth;
- повторное нажатие на демо отключает виртуальный самокат.

## 3. Управление

Блок подключения:

- поле ключа;
- кнопка авторизации;
- кнопка подключения к последнему устройству;
- кнопка отключения;
- строка состояния.

Основные команды:

- разблокировать;
- заблокировать;
- изъять батарею;
- найти самокат;
- применить настройки.

Настройки самоката:

- переключатель фары;
- три режима движения;
- переключатель газа;
- кнопка применения.

Спам:

- поле интервала;
- кнопка запуска;
- кнопка остановки;
- счётчик отправок и признак активности.

Телеметрия:

- батарея;
- скорость;
- пробег;
- запас хода;
- версия;
- напряжение;
- признак блокировки;
- кнопка обновления.

Сервисные команды:

- крышка батареи;
- перезапуск IoT;
- очистка Bluetooth;
- RGB-подсветка;
- питание;
- чтение конфига.

Консоль:

- выбор опкода из каталога;
- поле кода;
- поле payload в hex;
- кнопка отправки.

Кнопки команд недоступны, пока isReady=false. Это предотвращает отправку кадров без сессионного ключа.

## 4. GATT

Экран показывает полный список сервисов и характеристик, который вернул самокат.

Элементы:

- карточка с именем устройства, адресом, числом сервисов и характеристик;
- список сервисов с полным UUID, коротким UUID и свойствами характеристик;
- кнопка копирования дампа в буфер обмена;
- кнопка переподключения к последнему устройству.

Дамп публикуется после каждого discovery. Если Nordic UART отсутствует, в журнале появляется тег GATT с подсказкой о закрытой прошивке. Список сервисов сохраняется после отключения, чтобы его можно было скопировать.

## 5. Лог

Журнал показывает строки с временем, уровнем, тегом и текстом. Уровни:

- INFO: обычные события;
- TX: отправленные кадры;
- RX: принятые кадры;
- OK: успешные операции;
- WARN: отклонённые команды;
- ERR: ошибки.

Есть автопрокрутка, копирование всего журнала, копирование строки по долгому нажатию и очистка. Журнал хранится в памяти и ограничен 1000 строками.

## 6. Настройки

Блоки:

- тема;
- ключ BLE и пресеты NineHack и LostBot;
- интервал спама;
- автовозобновление спама;
- автопереподключение, число попыток и задержка;
- показ всех устройств;
- журнал сканирования;
- показ всех опкодов;
- демо-режим;
- проверка обновлений и установка APK;
- версия приложения.

Изменения сохраняются автоматически, кнопки сохранения нет. Числовые поля ограничиваются при потере фокуса. Смена темы пересоздаёт Activity. Смена демо-режима отключает текущее соединение. Выключение автопроверки не удаляет уже скачанный APK.

## 7. Обновления

- Автопроверка выполняется при запуске не чаще раза в сутки.
- Источник: последний релиз Codeberg с APK-ассетом.
- Версия из тега сравнивается с versionName.
- APK скачивается в кэш и устанавливается через FileProvider.
- На Android 8+ требуется разрешение на установку из этого источника.
- Кнопка проверки вручную запускает ту же цепочку и после загрузки меняется на установку.

## 8. Состояния

| Состояние | Текст | Доступность команд |
| --- | --- | --- |
| IDLE | Отключено | нет |
| SCANNING | Сканирование | нет |
| CONNECTING | Подключение | нет |
| DISCOVERING | Обнаружение сервисов | нет |
| AUTHENTICATING | Авторизация | нет |
| READY | Готово | да, если ключ принят |
| DEMO | Демо-режим | да |
| ERROR | Ошибка | нет |

При неверном ключе состояние READY, но authenticated=false. Строка состояния может выглядеть готовой, однако кнопки остаются отключёнными. Повторная авторизация выполняется кнопкой ключа.

## 9. Доступность

- Все кнопки имеют текстовые подписи.
- Размер интерактивных элементов соответствует Material 3.
- Темы проверяются на контраст.
- Горизонтальная прокрутка не используется, кроме длинных строк журнала.
- Клавиатура не перекрывает поля ввода благодаря adjustResize.
- Поддержка RTL включена, но тексты только русские.

## 10. Ограничения UI

- Нет экрана истории или графика телеметрии.
- Нет подтверждения для опасных команд, включая изъятие батареи и питание.
- Нет поиска по журналу.
- Нет экспорта журнала в файл.
- Нет выбора профиля команд NineHack или LostBot.
- Нет инструкции по подключению внутри приложения.

Эти ограничения перечислены в docs/roadmap.md.
