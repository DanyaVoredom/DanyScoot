# Частые вопросы

## Что такое DanyScoot

Android-клиент для BLE-команд самоката, работы с гарнитурами и внешними BLE-устройствами, а также AI-чат с инструментами приложения. Он не заменяет официальное приложение Urent и не работает с сервером аренды.

## Это официальное приложение

Нет. Это независимый проект на основе анализа сторонних APK. Urent не участвовал в разработке.

## Какие самокаты поддерживаются

Те, у которых есть сервис Nordic UART и протокол A3 A4. Точный список моделей неизвестен, потому что hardware-тест не проводился.

## Почему официальное Urent не подключается по BLE

В версиях 1.90.2 и 2.7.0 нет BLE-стека, BLE-разрешений, UUID 6e400001 и ключей. Официальный клиент использует серверные openlock и closelock.

## Откуда ключи

4BKNwi77 взят из NineHack, w4S3Hqn5 из LostBot. Это известные пресеты, а не универсальные ключи.

## Почему ключ не подходит

Ключ зависит от прошивки, партии или сервера. Без hardware-теста нельзя определить, какой ключ нужен. Возможен подбор, дамп прошивки или перехват официального клиента.

## Что такое sessionKey

Ключ, который самокат выдаёт после успешного рукопожатия. Он используется в последующих кадрах и сбрасывается при переподключении.

## Почему sessionKey 0

Ноль является допустимым значением. Ранее приложение ошибочно считало его ошибкой, это исправлено.

## Почему кнопка разблокировки не работает

Проверить:

- подключение и авторизацию;
- sessionKey;
- форму команды 0x05;
- журнал TX и RX;
- ответ 0x10;
- поддержку команды прошивкой.

## Чем спам отличается от обычной разблокировки

Спам отправляет 0x05 с временной меткой и повторяет его с заданным интервалом. Обычная кнопка отправляет 10 байт 01 в стиле NineHack.

## Почему две формы команды 0x05

Разные клиенты используют разные payload. DanyScoot поддерживает обе формы: одна для кнопки, другая для спама.

## Можно ли обновить прошивку

Нет. Приложение читает и логирует 0xFA, 0xFB и 0xFC, но не загружает образ. Это опасная операция, для которой нет проверенных данных.

## Какие сетевые запросы делает приложение

Только два вида: проверка и загрузка релиза GitHub и запросы к настроенному AI-серверу. Журнал и телеметрия не отправляются, пока пользователь не отправит сообщение в AI-чате.

## Работает ли приложение без Bluetooth

Да. Доступны настройки, журнал, GATT-дамп прошлого подключения и AI-чат. BLE-команды требуют подключения.

## Работает ли BlueStacks

Для UI да. Для BLE нет, потому что эмулятор не предоставляет Bluetooth LE.

## Поддерживаются ли гарнитуры Edifier

Да. Для Edifier используется сервис 00001100-d102-11e1-9b23-00025b00a5a5, батарея читается из 180F/2A19, метаданные из Device Information. Команды самоката для гарнитуры недоступны, но работают чтение, запись, подписка и уведомления.

## Что умеет AI

AI-чат поддерживает OpenAI Chat Completions, OpenAI Responses и Anthropic Messages. Модель может сканировать, подключаться, читать GATT, отправлять команды самоката и менять настройки через инструменты приложения.

## Насколько точно расстояние до устройства

Это оценка по RSSI с опорным значением -59 dBm на 1 метр и показателем потерь 2. Стены, тело и ориентация антенны сильно влияют на результат.

## Почему нет iOS

Проект использует Android BLE API и Android UI. iOS-версии нет.

## Где хранятся настройки

В SharedPreferences danyscoot_prefs. Ключ хранится в открытом виде. Backup отключён.

## Почему журнал пропадает

Журнал хранится в памяти и ограничен 1000 строками. При завершении процесса он очищается.

## Почему release подписан debug-ключом

Это временная конфигурация для локальной проверки. Для публикации нужен отдельный keystore и release signingConfig.

## Как проверить кадры

```
python references/verify_frames.py
```

Ожидаемый вывод: ok 72.

## Как сообщить об ошибке

Приложить модель телефона, версию Android, модель самоката или гарнитуры, версию прошивки, шаги, журнал без персональных данных и результат nRF Connect. Не прикладывать чужие ключи и API-ключи AI.
