# Совместимость

## 1. Android

| Версия | API | Поддержка | Примечание |
| --- | --- | --- | --- |
| 6.0 | 23 | да | минимум, разрешения выдаются при установке |
| 7.0..10 | 24..29 | да | геолокация нужна для скана |
| 11 | 30 | да | геолокация нужна для скана |
| 12 | 31 | да | BLUETOOTH_SCAN и CONNECT, neverForLocation |
| 13 | 33 | да | POST_NOTIFICATIONS, новый writeCharacteristic |
| 14 | 34 | да | без изменений |
| 15 | 35 | да | целевая версия |
| 16 | 36 | не проверено | compileSdk 36, поведение не тестировалось |

Приложение не поддерживает Android ниже 6.0. Это связано с API BLE и разрешениями.

## 2. Устройства

Требуется Bluetooth LE. Классический Bluetooth недостаточен.

Поддерживаемые признаки:

- сервис 6e400001-b5a3-f393-e0a9-e50e24dcca9e;
- характеристика записи 6e400002-b5a3-f393-e0a9-e50e24dcca9e;
- характеристика уведомлений 6e400003-b5a3-f393-e0a9-e50e24dcca9e;
- ответ на рукопожатие 0x01.

Если устройство использует другой сервис или UUID, приложение его не подключит. Список всех устройств показывает такие устройства, но подключение завершится ошибкой UART service not found.

## 3. Самокаты

Протокол восстановлен по клиентам, а не по прошивке. Совместимость с конкретной моделью не гарантирована.

| Семейство | Статус | Комментарий |
| --- | --- | --- |
| Urent с модулем Nordic UART | вероятно | ключи и команды из LostBot и NineHack |
| Urent с закрытым BLE | неизвестно | может требовать другого ключа или handshake |
| Другие самокаты с тем же протоколом | неизвестно | проверять на hardware |
| Официальное приложение Urent | не использует BLE | 1.90.2 и 2.7.0 не содержат BLE-стека |

Официальное Urent 1.90.2 и 2.7.0 использует серверные openlock и closelock. Отсутствие BLE в официальном APK не означает, что самокат не имеет BLE-модуля. Это означает только, что официальный клиент не подключается к нему напрямую.

## 4. Ключи

| Ключ | Источник | Статус |
| --- | --- | --- |
| 4BKNwi77 | NineHack strings.xml | известный пресет, не гарантия |
| w4S3Hqn5 | LostBot DI-провайдер | известный пресет, не гарантия |

Ключ хранится в SharedPreferences в открытом виде. Пользователь может ввести другой ключ. Длина не ограничена, но прошивка может ожидать ровно 8 байт.

Если ключ неверный, самокат не отвечает или отвечает статусом, отличным от 1. Приложение показывает ошибку и остаётся в READY без доступа к командам.

## 5. MTU

Запрашивается 247. Фактический MTU зависит от телефона, адаптера и прошивки. Если MTU не изменён, используется 23 и чанк 20 байт. Кадр до 255 байт payload требует до 14 чанков при MTU 23 и проходит в очередь 64.

## 6. Эмуляторы

BlueStacks, Genymotion, Android Studio Emulator и другие эмуляторы, как правило, не поддерживают Bluetooth LE. Демо-режим работает, реальное подключение нет.

Проверка в эмуляторе полезна только для UI и журнала. Она не подтверждает BLE-совместимость.

## 7. Прошивки

Версия прошивки приходит в ответе 0x31 в поле version. Приложение показывает major.minor.patch, но не использует версию для выбора команд.

Возможные различия:

- форма команды 0x05;
- поддержка 0x61;
- наличие 0x81;
- формат 0x31;
- необходимость времени в 0x05;
- требования к MTU.

Без hardware-теста эти различия не проверены.

## 8. Ограничения совместимости

- Нет выбора профиля протокола.
- Нет проверки модели.
- Нет автоматического подбора ключа.
- Нет обновления прошивки.
- Нет работы с серверным API Urent.
- Нет поддержки NFC.
- Нет поддержки iOS.
