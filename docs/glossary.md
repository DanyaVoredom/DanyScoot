# Глоссарий

## A

APK: Android Package, установочный пакет приложения.

ATT: Attribute Protocol, протокол атрибутов BLE.

## B

BLE: Bluetooth Low Energy.

Bonding: сохранение ключей сопряжения между устройствами.

## C

CCCD: Client Characteristic Configuration Descriptor, дескриптор включения уведомлений, UUID 2902.

CRC8: контрольная сумма кадра, отражённый полином 8C, эквивалент CRC-8/MAXIM, контрольное значение A1.

CRC16: контрольная сумма образа прошивки, полином A001, контрольное значение 4B37.

## D

Descriptor: дескриптор характеристики, например CCCD.

## G

GATT: Generic Attribute Profile, профиль BLE-сервисов и характеристик.

GATT 133: общий код ошибки Android BluetoothGatt.

## H

HCI snoop log: системный лог Bluetooth-обмена, используемый для анализа.

## I

IoT: модуль телеметрии и связи самоката.

## M

MAC: аппаратный адрес Bluetooth-устройства.

MTU: Maximum Transmission Unit, максимальный размер пакета BLE. По умолчанию 23, запрашивается 247.

## N

Nordic UART: профиль последовательного порта поверх BLE с UUID 6e400001.

Notify: уведомление от периферии к центральному устройству.

## O

Opcode: код команды в кадре.

OTA: обновление прошивки по воздуху.

## P

Payload: полезная нагрузка кадра.

## R

Rand: случайное число 1..254, используемое для XOR и маскировки wireRand.

RFID: радиочастотная идентификация, в протоколе используется для карт доступа.

RSSI: уровень сигнала BLE.

## S

Session key: ключ сессии, выданный самокатом после рукопожатия.

## T

TX: передача.

RX: приём.

## U

UART: универсальный асинхронный интерфейс, в BLE эмулируется профилем Nordic UART.

UUID: универсальный уникальный идентификатор сервиса или характеристики.

## W

WireRand: байт в кадре, равный rand + 50. XOR выполняется с исходным rand.

Write without response: запись без подтверждения на уровне GATT.

Write with response: запись с подтверждением onCharacteristicWrite.
